## 3. Generation pipeline (W-6 plan)

```
brand-application.md (colors, typography, voice)
        ↓
NanoBanana (Gemini 2.5 Flash Image) — image-to-image edit mode for brand consistency
        ↓
Imagen (only if hero photorealism needed — currently no need at Day 1)
        ↓
ImageMagick / sharp / cwebp — size-matrix export
        ↓
pngquant / oxipng / svgo — optimize
        ↓
assets/source/{asset-id}.json — generation metadata (prompt + seed + model)
        ↓
This manifest — file paths + dimensions + file sizes + status
```

## 4. Validation gates (W-6)

Per team-design D14a:
- Every required slot in §1 has an asset.
- Icons readable at 16×16.
- OG cards have no text breaking at small-preview rendering.
- Lottie JSONs parse + play (`lottie-react` smoke test).
- File size budgets: icons < 50KB except 1024×1024; OG cards < 300KB; hero < 500KB; Lottie < 100KB.
- Every color reference traces to a brand token (no off-brand colors in any asset).
